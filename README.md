Automatic thumbnail generator **compatible with MKS TFT 3.5” screens** for **Orca Slicer**, optimized for **Hellbot Magna 2** using **MKS Robin Nano** mainboards.

The executable is used as a **post-processing script** and inserts thumbnails directly into the G-code file, allowing the printer screen to display an accurate preview of the printed model.

---

## ✨ Features

* Generates **100×100** and **200×200** thumbnails
* **100% compatible with MKS TFT 35** format
* Direct rendering at final resolution (no upscaling, no pixelation)
* Black background, matching factory G-code files
* **Multi-color print support**
* Full use of the MKS screen color palette (lighting and shading)
* Fully automatic
* **No Python or external dependencies required**

---

## 🖥️ Compatibility

* Orca Slicer
* **MKS TFT 35 (3.5") touch screen**
* Hellbot Magna 2
* MKS Robin Nano boards

May also work on other MKS-based printers using the same thumbnail format.

---

## 🚀 Installation & Usage

1. Download `magna_mks.exe`
2. Open **Orca Slicer**
3. Go to **Preferences → Post-processing Scripts**
4. Add the `magna_mks.exe` executable
5. Slice the model and save the G-code

The generated G-code will already include MKS-compatible thumbnails.

---

## 📦 Distribution

The executable is **standalone**:

* No Python required
* No libraries to install
* Can be freely shared

Only the `.exe` file is needed.

---

## ⚠️ Notes

* Windows may display a security warning the first time the executable is run (normal behavior for unsigned executables).
* Orca Slicer does not display the executable icon, but Windows Explorer does.

Generador automático de miniaturas **compatibles con pantallas MKS TFT 3.5”** para **Orca Slicer**, optimizado para **Hellbot Magna 2** con placa **MKS Robin Nano**.

El ejecutable se utiliza como **post-processing script** y se encarga de insertar miniaturas directamente dentro del archivo G-code, permitiendo que la pantalla de la impresora muestre una vista previa correcta del modelo.

---

## ✨ Características

- Genera miniaturas **100×100** y **200×200**
- Formato **100% compatible con MKS TFT 35**
- Render directo en resolución final (sin escalado ni pixelado)
- Fondo negro, como los G-code originales de fábrica
- Soporte para **impresiones multicolor**
- Uso completo de la paleta de colores de la pantalla
- Totalmente automático
- **No requiere Python ni dependencias externas**

---

## 🖥️ Compatibilidad

- Orca Slicer
- Pantalla táctil **MKS TFT 35 (3.5")**
- Hellbot Magna 2
- Placas MKS Robin Nano

Puede funcionar en otros equipos MKS compatibles con el mismo formato de miniaturas.

---

## 🚀 Instalación y uso

1. Descargar el archivo `magna_mks.exe`
2. Abrir **Orca Slicer**
3. Ir a **Preferences → Post-processing Scripts**
4. Agregar el ejecutable `magna_mks.exe`
5. Laminar el modelo y guardar el G-code

El G-code generado ya incluirá las miniaturas compatibles con la pantalla MKS.

---
