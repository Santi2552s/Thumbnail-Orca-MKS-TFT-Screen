# Thumbnail-Orca-MKS-TFT-Screen
Post-processing executable for Orca Slicer that automatically generates MKS-compatible thumbnails for TFT 3.5” screens (Hellbot Magna 2 / MKS Robin Nano). Embeds 100x100 and 200x200 previews directly into the G-code, with proper rendering, black background and multi-color support. No Python required.
